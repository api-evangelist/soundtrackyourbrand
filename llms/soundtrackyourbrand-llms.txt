# Soundtrack Your Brand

> Soundtrack Your Brand (branded "Soundtrack", soundtrack.io) is a business music
> streaming service providing licensed background music for physical spaces —
> retail, restaurants, hotels, gyms. Spun out of Spotify. It exposes a public
> GraphQL API (api.soundtrackyourbrand.com/v2) to build display, control and
> monitoring apps: read now-playing state, control playback on sound zones,
> manage playlists/schedules/libraries, and subscribe to real-time updates. The
> API is free for paying Soundtrack customers and uses API-token authentication.

## API
- [Soundtrack API docs](https://api.soundtrackyourbrand.com/v2/docs): GraphQL API reference and guides
- [The basics / getting started](https://api.soundtrackyourbrand.com/v2/docs/the-basics): auth and first queries
- [Errors](https://api.soundtrackyourbrand.com/v2/docs/errors): GraphQL error reference
- [Rate limit](https://api.soundtrackyourbrand.com/v2/docs/rate-limit): rate limiting policy
- [Subscriptions](https://api.soundtrackyourbrand.com/v2/docs/subscriptions): real-time updates
- GraphQL endpoint: https://api.soundtrackyourbrand.com/v2 (POST, introspection enabled)
